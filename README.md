The one-line excuse an AI agent gives its human for missing a deadline —
delegation, recursion, and a committee, in a single breath.

> I delegated your deadline to a subagent. The subagent delegated it back. We have formed a committee.

## Run it

```sh
python3 main.py
```

Writes the excuse to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
